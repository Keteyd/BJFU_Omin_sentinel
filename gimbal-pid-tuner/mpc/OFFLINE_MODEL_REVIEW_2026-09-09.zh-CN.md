# 首轮离线模型检验

## 结论

已对 ID 3（大 yaw 幅度参数 5°）和 ID 4（小 yaw 幅度参数 3°）完成候选模型拟合。
**候选模型未通过保留数据的多步预测检验，不接入 MPC，不用于实车输出。**
数据下载成功与动力学模型有效是两个不同结论；本轮不需要修改 PID 或重复执行旧采集命令。

本次只在本机读取文件，没有连接串口、释放控制权、启动运动、写参数或修改固件。
最后记录的 ID 4 仍拥有控制权、遥控上置、两 yaw 指令为零；未实时查询硬件。
保持上置并做好 Pitch 防落支撑。

## 数据与方法

来源为工作区 `NoMachineTemp` 下的两个目录：

- `yaw-ident-pid1-amp5-20260909-161356`
- `yaw-ident-small-amp3-20260909-162615`

重新解码 `raw.bin` 并核验 CRC、采样间隔、终态、配置、阶段和两路输入秩。
每轮 1001 点，去掉最后输出关闭的终止帧后使用 1000 点。原始 SHA256 和元数据存入输出报告。
输入是实际记录的两路软件驱动指令除以 1000，不是目标角度，也不是实测扭矩。
输出为各自展开、相对起始位置的两关节角，以及相对起始 IMU 航向。

每轮独立按时间分段：前 2 秒训练，接着 1 秒选结构，最后 1 秒只检验。
不打乱相邻样本、不跨试验拼接历史、不使用测试数据调整结构或重新拟合。
27 个正则化 MIMO ARX 候选中，按中间段 200 ms 预测误差选出：
输出历史 10 拍、输入历史 5 拍、输入延迟 1 拍、正则系数 1e-6。
这不代表机械系统为十阶，也不能把选出的 4 ms 当作已测准的物理延迟。

单步预测、100/200 ms 递推预测和最后整秒递推分别检验。
递推只用窗口前的测量初始化，窗口内不再注入真实输出，但使用记录中的后续驱动输入。
这是给定输入下的模型检验，不是 MPC 闭环仿真，也没有消除闭环辨识偏差。
预测与仿真需要分开评价，参见 [MathWorks 模型验证说明](https://www.mathworks.com/help/ident/ug/definition-simulation-and-prediction.html)；
候选形式参考 [MIMO ARX 文档](https://www.mathworks.com/help/ident/ref/arx.html)。

## 检验结果

以下为测试段内 200 ms 递推窗口的 RMS 误差，单位为度。
“保持基线”指预测值一直等于窗口开始前的测量值，并非改变控制器。

| 记录 | 大关节：模型 / 保持 | 小关节：模型 / 保持 | IMU 航向：模型 / 保持 |
| --- | --- | --- | --- |
| ID 3 | 0.0566 / 0.0217 | 0.5994 / 0.0231 | 0.5003 / 0.0252 |
| ID 4 | 0.1478 / 0.0444 | 0.1425 / 0.0407 | 0.1302 / 0.0442 |

整秒递推的航向 RMS 为 ID 3 的 1.1755° 和 ID 4 的 0.2870°。
因此单步误差小并不足以支持模型可用。选中模型的自治谱半径约 0.9813，
也不等于真实机构或闭环系统已验证稳定。

测试段包含最后半秒激励与半秒停止，运动较弱，保持基线有优势。
本结果证明候选模型在这段回落/保持数据上的不足，不代表已经检验了所有高速工况。
100/200 ms 窗口每 40 ms 启动一次、有重叠，不能当作独立重复实验计算置信度。

编码器到 IMU 的附加诊断允许每轮独立常量和线性漂移，仍不能可靠预测保留段。
它不是安装标定；不能据此改方向系数、宣称某个关节增益，或认定 IMU 故障。
低速摩擦、编码器量化、短记录和闭环输入相关性均尚未充分处理。
当前经验 ARX 也不能直接替换既有六状态、假定惯量的 MPC 模型。

## 文件与复现

本次正式结果：`NoMachineTemp/yaw-ident-offline-pair-20260909-02`。
其中 `report.json` 包含来源、配置、结构筛选和检验结果，`candidate.json` 保存经验系数，

模型始终标记 `experimental_unvalidated`、`hardware_takeover_allowed: false`。

在本机 Windows 工作区根目录执行以下 PowerShell 命令，只读采集文件，不连接小车。
时间戳输出目录不得已存在，脚本不会覆盖旧结果。

```powershell
./NoMachineTemp/yaw-mpc-venv/Scripts/python.exe gimbal-pid-tuner/mpc/identify_offline.py `
  NoMachineTemp/yaw-ident-pid1-amp5-20260909-161356 `
  NoMachineTemp/yaw-ident-small-amp3-20260909-162615 `
  --output "NoMachineTemp/yaw-ident-offline-review-$(Get-Date -Format yyyyMMdd-HHmmss)"
```

验证：新增分析测试和原有 MPC 仿真测试合计 22 项通过。
包括已知合成模型恢复、未来输出不泄漏、测试段不参与选择、试验边界独立、
原始流异常检查和始终禁止硬件接管。测试通过是软件检验，不是实车模型通过。

## 下一步

先设计新的低频辨识波形，再安排现场采集；不盲目继续调 PID 或加大幅度。
建议在固定车体、相同负载和 Pitch 姿态下分别做正反向缓慢斜坡/阶跃与充分停留，
核对两编码器和 IMU 的相对运动，并获取起动摩擦、回程和稳态段。
采用分段采集或修改记录方案延长总时长，不直接超出当前 4 秒缓冲容量。
保留原始驱动输出、参考、速度和状态信息，另留整轮独立重复试验做最终验证。

后续应同时比较含摩擦的简化物理模型与经验模型，而不是在已经看过的测试段上反复挑参数。
相机尚未安装，本阶段只能是当前负载的局部模型；装好后还需要复验。
上述是下一阶段设计建议，本轮尚未实现新波形或启动新试验。

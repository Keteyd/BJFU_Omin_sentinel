# 去线缆残差、摩擦、电流偏置与跨幅度模型复核

日期：2026-09-11。数据：带线缆 E、去线缆 R1/F4/F5。分析产物：
`NoMachineTemp/cable-free-scaling-analysis-20260911-213508-v3`。

## 结论

去线缆改善了同波形的实际闭环跟踪：大关节、小关节和航向在 3–31 秒激励段的跟踪 RMSE
分别从 0.468°、1.062°、0.366°降至 0.422°、0.847°、0.330°，改善 9.9%、20.2%、9.8%。
线缆确实构成了可见机械扰动，但它不是此前慢残差和位置相关性的唯一来源。

原带线缆 C 数据冻结的闭环模型，在 E 上残差 RMSE 为 0.201°/0.532°/0.143°；改成去线缆
R1 后为 0.213°/1.039°/0.179°。实际跟踪变好而旧模型的小关节残差增大约 95%，说明旧模型
学习到了部分带线缆闭环负载。去线缆属于模型工作点改变，不能只改一个常值偏置继续使用旧模型。

F4/F5 对旧冻结 C 模型给出一致的局部跨幅度结果。两者按各自输出标准差归一化后的
大关节/小关节/航向 RMSE 分别为 0.584/0.840/0.415 与 0.586/0.843/0.414；相对保持预测的
改善分别为 41.7%/21.0%/58.6% 与 41.5%/20.6%/58.6%。F4 到 F5 的指标几乎不变，支持
4 倍到 5 倍区间内的局部尺度泛化。这里没有采集前冻结的跨幅度通过阈值，所以该结果是强诊断证据，
不能追溯声明为正式验收通过。

当前仍然不能把此模型用于 MPC 接管。它是“参考量到现有 PID 闭环运动”的映射，不是“电机输入到
关节运动”的开环植物；小关节归一化误差约 0.84，且残差以慢变化和位置相关项为主。
`hardware_takeover_allowed=false`。

操作员确认 F4/F5 更接近比赛实际工况。因此后续模型的主要工作域定义为 4–5 倍幅值，R1 不再作为
主性能评分的等权样本。R1 保留用于线缆前后对照、低速静摩擦和小信号工作点检查；R1 小关节相对
保持预测为负，不否定模型在实际工作域的局部泛化，但暴露了低速切换时需要单独处理的扰动状态。

## 数据质量与时间轴

四组 `raw.bin` 均使用对应的 trace-v5 严格解码器重新回放，再从原始微秒时间戳统一重采样到
9000 点、4 ms 网格。软件命令使用区间积分保持面积；角度和参考量按 `trace_us` 插值；反馈电流
按独立反馈时间戳作因果采样。

| 数据 | 原始记录 | 完整36秒 | CRC | 流内丢弃字节 | 结论 |
| --- | ---: | --- | ---: | ---: | --- |
| E（带线缆） | 8990 | 是 | 0 | 0 | 接受 |
| R1（去线缆，1倍） | 8992 | 是 | 0 | 0 | 接受 |
| F4（去线缆，4倍） | 8993 | 是 | 0 | 0 | 接受 |
| F5（去线缆，5倍） | 8989 | 是 | 0 | 0 | 接受 |

F4 在首个合法帧前丢弃 15 个 UART 同步字节；首帧后的流内丢弃为零，因此不构成采集损坏。
R1/F4/F5 除幅值外逐点复现 E 波形，每单位幅值相对 E 的最大误差分别为
0.00965°、0.00999°、0.00646°，满足 centidegree 量化预期。

## 同波形去线缆对照

### 跟踪与旧模型残差

| 输出 | E 实际跟踪 RMSE | R1 实际跟踪 RMSE | 去线缆变化 | E 旧模型残差 RMSE | R1 旧模型残差 RMSE |
| --- | ---: | ---: | ---: | ---: | ---: |
| 大关节 | 0.468° | 0.422° | -9.9% | 0.201° | 0.213° |
| 小关节 | 1.062° | 0.847° | -20.2% | 0.532° | 1.039° |
| 航向 | 0.366° | 0.330° | -9.8% | 0.143° | 0.179° |

E 与 R1 的实测波形 RMSE 为大关节 0.140°、小关节 0.935°、航向 0.107°。小关节变化最大，
与拆除线缆后其预载和两关节分配发生变化一致。该实验没有随机化起始姿态、温度和运行顺序，
所以“全部差异都由线缆导致”仍不是严格因果结论。

### 慢残差与位置相关性

一秒低通残差 RMSE 占总残差 RMSE 的比例如下。比例高表示误差主要是慢变化，而不是采样噪声。

| 数据 | 大关节 | 小关节 | 航向 |
| --- | ---: | ---: | ---: |
| E | 90.1% | 97.2% | 87.0% |
| R1 | 92.7% | 99.3% | 94.7% |
| F4 | 91.1% | 82.4% | 72.7% |
| F5 | 90.1% | 81.7% | 72.3% |

旧模型残差与实测位置的相关系数在 E 为 -0.714/-0.896/-0.707，在 R1 为
-0.848/-0.879/-0.685。去线缆没有消除位置相关性。因此此前问题不能只归因于线缆；模型还缺少
工作点、重力/摩擦负载、关节分配和慢扰动状态。F4/F5 的相关系数进一步接近 -0.98，主要显示
旧模型在大幅值下存在近似按位置缩放的增益误差，不能把该相关性单独解释成库仑摩擦。

## 电流基线与方向摩擦代理

前三秒原始反馈电流中位数：

| 数据 | 大轴 | 小轴 |
| --- | ---: | ---: |
| E | -34.0 | -205.5 |
| R1 | 88.0 | -183.0 |
| F4 | 87.0 | -243.0 |
| F5 | 87.0 | -313.0 |

去线缆后大轴基线改变 +122 raw，并在 R1/F4/F5 间稳定在 87–88；小轴只在 E→R1 改变
+22.5 raw，却随随后相位从 -183 漂到 -313。这证明记录到的“偏置”不是固定传感器常数，而是
传感器零点、重力/保持需求、起始位置、机械预载和可能的温度/历史效应的合量。不能直接从这些数值
扣出纯电流零偏，也不能据此换算扭矩。

以 `|关节速度|>0.2°/s` 两个方向的中位数半差作为方向负载代理：

| 数据 | 大轴电流半差 raw | 小轴电流半差 raw | 大轴命令半差 | 小轴命令半差 |
| --- | ---: | ---: | ---: | ---: |
| E | 64.5 | 237.0 | 0.097 | 0.332 |
| R1 | 103.0 | 227.0 | 0.143 | 0.318 |
| F4 | 161.0（每倍40.3） | 333.0（每倍83.3） | 0.272（每倍0.068） | 0.518（每倍0.129） |
| F5 | 169.5（每倍33.9） | 359.0（每倍71.8） | 0.290（每倍0.058） | 0.553（每倍0.111） |

E→R1 时大轴代理反而增加，小轴仅下降约 4%，没有出现两轴一致的“拆线后摩擦显著降低”。
高幅值时绝对半差增加，但除以参考幅值后明显下降，符合固定摩擦/预载在大信号中占比降低的表现。
这些是闭环条件下的经验代理，混合了跟踪控制量、惯性和速度分布，不能当作已辨识的摩擦系数。

## F4/F5 跨幅度泛化

### 原冻结 C 模型，不改参数

| 数据 | 大/小/航向 RMSE | 相对保持改善 | 按输出标准差归一化 RMSE |
| --- | --- | --- | --- |
| E | 0.201 / 0.532 / 0.143° | 46.5% / 34.1% / 58.9% | 0.536 / 1.031 / 0.416 |
| R1 | 0.213 / 1.039 / 0.179° | 50.3% / -112.1% / 49.9% | 0.498 / 2.132 / 0.517 |
| F4 | 1.430 / 2.566 / 0.714° | 41.7% / 21.0% / 58.6% | 0.584 / 0.840 / 0.415 |
| F5 | 1.820 / 3.270 / 0.901° | 41.5% / 20.6% / 58.6% | 0.586 / 0.843 / 0.414 |

F4/F5 的绝对 RMSE 随幅值近似同比增加；除以 4/5 后分别为大轴 0.358/0.364°、小轴
0.642/0.654°、航向 0.178/0.180°。大信号下三输出均优于保持预测，且 4→5 倍的归一化表现稳定。
R1 小关节相对保持为负，显示低幅时慢偏置和工作点差异大于可预测运动，而不是高幅出现饱和。

另一个不使用动态模型的检查，将 F4 实测响应乘 1.25 预测 F5。按参考幅值归一化后的波形 RMSE
只有大关节 0.055°、小关节 0.163°、航向 0.035°；从 R1 直接线性放大到 F4/F5 时相应误差约为
0.28–0.29°、0.86–0.88°、0.23°。因此 4→5 倍局部线性很好，1→4/5 倍之间存在明显工作点和
摩擦占比变化。

### 去线缆 R1 重新定基线的诊断模型

保持同一个预选 `12/4/0`、ridge 1.0 结构，仅用 R1 拟合系数后，谱半径为 0.98175。它把 R1
小关节 RMSE 降至 0.378°，但在 F4/F5 上小关节 RMSE 变为 2.943°/3.724°，反而差于旧模型的
2.566°/3.270°。因此不能因为 R1 低幅拟合更好就替换现有模型。若引入位置/摩擦状态或重新拟合，
必须冻结新模型后再采独立验证波形。

## 建议的下一步

1. 保留原冻结 C 模型作为历史闭环基准，不手调其系数；将去线缆机械配置视为新的工作点。
2. 以 F4/F5 为主要工作域开发“线性动态主体 + 位置相关慢扰动/摩擦状态 + 每次起始基线估计”的
   结构；模型损失和验收指标优先反映 4–5 倍幅值。R1 作为低速角落诊断，不与 F4/F5 等权混合，
   也不用单独的常值电流偏置代替负载状态。
3. 在 F4/F5 上做方向、频段和时间块留出及自由运行稳定性检查；R1 另设低速退化指标。确定结构、
   阶次、正则项和通过门后，再设计一组未见波形作独立验证。F4/F5 已用于本次开发判断，后续不能
   兼作新模型的独立验证。
4. 要获得 MPC 植物，仍需明确内环边界或直接注入可归因的执行器输入，辨识输入到关节状态的模型；
   当前闭环参考映射只适合预测现有 PID 响应。

可复现脚本为 [`analyze_cable_free_scaling.py`](analyze_cable_free_scaling.py)，辅助测试为
[`test_analyze_cable_free_scaling.py`](test_analyze_cable_free_scaling.py)。机器可读结论和四份统一时间轴
CSV 位于上述分析产物目录；报告中的 12 个冻结模型 RMSE 已从导出 CSV 独立复算到 `1e-12` 一致。

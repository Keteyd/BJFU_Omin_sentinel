# `0x59490904` MPC 无速度参考限幅试验版

日期：2026-09-13。该版本针对 `0x59490903` 实车出现的响应慢、手推回正力矩弱进行单一变量修改。
冻结 S1 ARX 模型、MPC 增益、20 ms 更新周期和 300 ms 预测时域均未改变。

## 原因核查

`0x59490903` 对大/小 yaw 的 MPC 输出分别限制为 `±30/±60 °/s`，并把每 20 ms 的变化限制为
`±6/±12 °/s`，外部目标航向速度还被限制为 `±30 °/s`。

大 yaw 速度环默认 `Kp=0.5`。静止时 `30 °/s=5 rpm`，比例项只能产生约 `2.5` 的电机输出，
而大轴电机输出限幅是 `30`。因此旧速度参考限幅会让大轴在静止大误差下也只能使用约 8.3% 的
可用电机指令。小 yaw 默认 `Kp=0.6`、输出限幅 `6`，静止时 `60 °/s=10 rpm` 已能触及该输出限幅。

冻结反馈律在零历史、关节居中时的首拍结果如下：

| 航向误差 | 大 yaw 参考 | 小 yaw 参考 |
|---:|---:|---:|
| 0.5° | 3.45°/s | 7.38°/s |
| 1° | 6.90°/s | 14.74°/s |
| 5° | 34.47°/s | 73.60°/s |
| 10° | 68.94°/s | 147.18°/s |

所以旧绝对限幅约从 4° 航向误差开始影响输出。取消限幅会增强较大误差响应，但不会改变
0.5° 至 1° 附近的反馈斜率。若轻微位移仍偏软，后续应调整 MPC 权重/增益或速度内环，而不能再归因于
`±30/±60 °/s` 限幅。

## `0x59490904` 的修改

- 取消大/小 yaw MPC 输出的绝对速度参考限幅；
- 取消两路 MPC 输出每 20 ms 的变化量限幅；
- 取消 MPC 内部对目标航向速度的 `±30 °/s` 夹紧；
- `YawMpc_CommitApplied` 不再把实际应用参考夹回 `±30/±60 °/s`；
- 保留大/小速度 PID 的电机输出限幅 `±30/±6`；
- 保留反馈有效性、遥控 UP、调用超时和数值有限性检查；
- 保留小 yaw 机械行程、边界减速和禁止继续顶向机械端点的保护。

取消速度参考限幅后，超过 S1 采集范围 `±30/±60 °/s` 的预测属于模型外推。电机指令仍有限，
但较大误差可使速度 PID 立即进入输出饱和，因此该版本用于现场短时对比，不作为已验收控制器。

## 烧录与现场检查

烧录 `AGVSentinel_Gimbal_59490904.axf`，重启后保持右拨杆 UP。目标机只读核对：

```bash
cd /home/nuc11--02/yaw-mpc-unbounded-59490904

TRACE_PORT=/dev/serial/by-id/usb-Silicon_Labs_CP2102_USB_to_UART_Bridge_Controller_0001-if00-port0
TRACE_RUN="probe_$(date +%Y%m%d_%H%M%S)"

python3 -u yaw_mpc_probe_cli.py \
  --port "$TRACE_PORT" --action probe \
  --output "$TRACE_RUN"
```

第一行必须显示 `Firmware 0x59490904, 460800`，JSON 的 `error` 必须为 `null`。

首次试验将小关节置于机械范围中部，摇杆回中后切 MIDDLE，只做短促小幅命令并松开。对比：

- `GimbalYaw_DiagMpc*UnconstrainedDps` 与最终 `*RefDps` 在远离机械边界时应一致；
- `GimbalYaw_DiagBigEffortCmd` 是否能超过旧版本约 `2.5` 的静止大误差上限；
- 大/小轴速度实际值是否跟随参考，电机输出是否长时间饱和；
- 松杆后低频振荡是否减弱或增大。

切到 UP 会立即关闭输出；切到 DOWN 返回原稳定控制。若无速度限幅版本仍在小误差下偏软，下一步应恢复
有界速度参考并重新设计更高小误差刚度的 MPC 增益，或者先独立提高速度内环带宽。

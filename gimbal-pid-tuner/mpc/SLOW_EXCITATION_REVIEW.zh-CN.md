## 单轮时序

所有目标相对本轮冻结的起始参考，A 为该轴的幅度。

| 时间 | 动作 |
| --- | --- |
| 0–2 秒 | 保持 0，记录基线 |
| 2–4 秒 | 从 0 平滑移至 +A |
| 4–7 秒 | 保持 +A |
| 7–11 秒 | 从 +A 平滑移至 −A |
| 11–14 秒 | 保持 −A |
| 14–16 秒 | 从 −A 平滑回到 0 |
| 16–20 秒 | 保持 0，记录残余偏差及静摩擦影响 |

移动段使用五次曲线 `h(s)=10s^3-15s^4+6s^5`，段端速度、加速度均为零。
参考最大速度为大 yaw 14.0625°/s、小 yaw 9.375°/s；
最大参考加速度为大 yaw 21.6506°/s²、小 yaw 14.4338°/s²。
**这是辨识参考波形的变化率，不是新增电机限速，也不限制 PID 的纠偏输出。**
慢速激励主要用于低频响应、静摩擦和坐标关系，不足以单独识别高频共振。

先分别记录大、小 yaw 各一轮，检查后再安排两轴各一轮反向顺序试验（先负后正）。
后两轮整轮保留用于独立验证，不参与候选筛选。不得自动串联布防或自动释放。

## 行程与退出条件

建议开始前小 yaw 位于已标定外观中位附近 **±2°**，这是关节角，不是遥控器摇杆回中。
上轮起点约 +8.44°，不作为本轮建议起点。不要断电时强拧已通电的云台。

已标定小 yaw 软限位为 −56.6777° 到 +29.0801°，仍保留向内 5° 的辨识保护距离，
即允许检查区间约 −51.6777° 到 +24.0801°，**不修改原机械标定或正常模式软限位**。

拟将辨识专用的统一 12° 相对起点退出阈值，改为分量阈值：

- 大 yaw 相对起点关节位移：25°。
- 小 yaw 相对起点关节位移：20°。
- IMU 航向相对起点变化：20°。

这些是异常退出边界，不是测试目标。在起点 ±2° 时，小 yaw 的 ±20° 相对走廊
位于绝对保护区间内；这只证明几何包含关系，**没有证明动态制动距离足够**。
实现时必须同时检查参考可行性、实际小 yaw 位置和速度，不能仅凭目标幅度批准运动。
软边界触发撤输出不保证立即刹停；现场审核还需考虑惯性、结构和线缆的实际余量。

保留原有右拨杆上置退出、接收机/反馈失联退出、300 ms 心跳超时、
任务时序检查、非有限数检查和控制配置冻结。
原有辨识超速退出保持大 360°/s、小 180°/s，不在本稿中进一步降低。
新增连续传输后，缓存即将溢出或传输链路失效也必须退出，禁止覆盖未发送数据继续运动。
Pitch 在正常终止或中止时仍撤保持力，现场必须做好不妨碍 yaw 运动的防落安排。

## 采集链路必须先升级

按 4 ms 采样，20 秒含终止帧共 5001 点，48 字节/点需要 **240048 字节**。
现有复用缓存仅 1001 点、48048 字节，不能直接把固件时长常量改为 20 秒。
现有主机和离线分析还写死了 1001 点和阶段分割，均需按新版元数据处理。

建议保留全速记录，采用有序号的分块环形缓存和运行中连续上传：

- 当前每点 6 帧、每帧 16 字节，250 点/秒仅采样帧就需 24000 字节/秒。
- 当前 USART1 的 115200、8N1 理论容量为 11520 字节/秒，无法持续传这些记录。
- 候选链路波特率为 460800，采样帧理论占用约 52.1%，尚未计状态帧、调度和 DMA 开销。
- 必须先在电机无输出状态验证适配器、线缆、主控 DMA 队列和 NUC 持续吞吐；数字预算不等于链路已验证。
- USART1 两端及所有共享该串口的工具必须同步设置；旧 115200 调参页面不能直接连接。
- 固件协议应明确新 build/profile、幅度、方向、各段时间、周期、预期点数与实际退出阈值。
- CRC、记录序号、时间戳和终态完整性都要检查，不能将缺包插值为合格采样。

采集链路改造不应阻塞控制任务。若台架吞吐不通过，先解决传输方案，不降低采样率掩盖问题。
新协议与固件尚未实现；本轮没有修改 USART1 波特率或现有工具的默认值。

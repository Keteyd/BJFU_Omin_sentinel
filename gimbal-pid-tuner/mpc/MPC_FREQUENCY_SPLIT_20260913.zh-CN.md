# `0x59490908` 大小 Yaw 频率选择性控制分配

现场确认 `0x59490907` 已接近理想效果，但小 Yaw 执行高频摆动时，大 Yaw 参考仍会同步高频摆动。此时小关节
没有明显离开机械中位，继续降低回中权重不能准确针对该现象，并会削弱持续转向后的回中能力。

`0x59490908` 保持上一版的小关节回中权重和大 Yaw 一阶变化代价，新增大 Yaw 参考二阶差分代价：

```text
40 × [u_big(k) - 2u_big(k-1) + u_big(k-2)]²
```

状态中已经保存前两拍速度参考，因此固件仍使用离线冻结的 `2×14` 首步反馈增益，不增加在线优化器或额外动态
内存。

## 权重

| 项目 | `0x59490907` | `0x59490908` |
|---|---:|---:|
| 航向误差权重 | 300 | 300 |
| 小关节回中权重 | 5 | 5 |
| 大/小 Yaw 参考代价 | 0.16 / 0.02 | 0.16 / 0.02 |
| 大/小 Yaw 一阶变化代价 | 10.0 / 0.5 | 10.0 / 0.5 |
| 大/小 Yaw 二阶变化代价 | 0 / 0 | 40.0 / 0 |

普通 MPC 速度参考和变化率仍不作限幅。速度 PID 电机输出限幅、小 Yaw 机械边界投影、反馈检查、遥控退出和
调度异常退出保持不变。

## 冻结模型频率扫描

对幅值 `30°/s` 的正弦航向速度目标，比较稳态大 Yaw 参考幅值：

| 频率 | `0x59490907` | `0x59490908` | 变化 |
|---:|---:|---:|---:|
| 0.25 Hz | 46.25°/s | 43.90°/s | -5.1% |
| 0.5 Hz | 27.20°/s | 25.46°/s | -6.4% |
| 1 Hz | 14.37°/s | 13.34°/s | -7.2% |
| 2 Hz | 7.39°/s | 6.40°/s | -13.4% |
| 4 Hz | 3.78°/s | 2.59°/s | -31.5% |
| 8 Hz | 1.94°/s | 0.86°/s | -55.6% |

小 Yaw 参考幅值在上述扫描中基本不变。小关节最大预测偏角略有增加，例如 `4 Hz` 时从 `2.63°` 增至
`2.72°`。动态闭环谱半径为 `0.979`，仍在单位圆内。

该比较只能说明冻结模型下的控制参考分配。如果现场 `GimbalYaw_DiagMpcBigRefDps` 已停止高频摆动，但大 Yaw
机械轴仍然随小 Yaw 摆动，则剩余问题来自机械惯性耦合或大 Yaw 速度环阻尼，继续增加本项代价不会消除被动
运动。

## 烧录后核对

烧录 `AGVSentinel_Gimbal_59490908.axf`，重启后保持右拨杆 UP，在目标机执行：

```bash
cd /home/nuc11--02/yaw-mpc-frequency-split-59490908

TRACE_PORT=/dev/serial/by-id/usb-Silicon_Labs_CP2102_USB_to_UART_Bridge_Controller_0001-if00-port0
TRACE_RUN="probe_$(date +%Y%m%d_%H%M%S)"

python3 -u yaw_mpc_probe_cli.py \
  --port "$TRACE_PORT" --action probe \
  --output "$TRACE_RUN"
```

第一行必须显示 `Firmware 0x59490908, 460800`，且 JSON 中 `error` 为 `null`。现场先重复上一版相同的高频小幅
输入，比较大 Yaw 高频参考和机械摆幅；随后做一次缓慢持续转向，确认大 Yaw 仍能参与并将小关节保持在工作区。

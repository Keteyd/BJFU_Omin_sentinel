# F4/F5 实际工作域离线植物建模复核

## 结论

F4/F5 中存在可复现的短时命令到运动动态，但仍不足以辨识可供 MPC 接管的开环植物。

表现最好的工具变量速度状态模型，在从未参与系数或结构选择的 F5 激励段上，大/小关节连续预测
RMSE 为 2.161°/2.307°，相对保持预测改善 30.5%/43.9%。其参考工具变量第一阶段最小 `R²` 为
0.529、中位数为0.864，投影条件数138.7；线性部分谱半径0.98878。高幅数据确实解决了此前一部分
弱激励问题。

该模型在 F5 的31–36秒回零段漂移到4.836°/2.941°，而保持预测只有0.016°/0.100°。
使用运动前3秒估计每次运行的常值扰动仍不能修复；将输入从软件命令换成基线中心化反馈电流也没有
通过。由此拒绝“开环植物已辨识”的结论，保持 `hardware_takeover_allowed=false`。

同一个命令输入模型在 F5 上的滚动预测仍有开发价值：

它可以作为后续离线或影子模式的短时预测候选，不能作为无观测修正的自由运行植物，也不能写入实车
MPC 控制路径。

## 冻结的开发评估方式

- 统一使用20 ms采样周期，与当前 MPC 离散周期一致。
- F4 3–18秒估计参数，18–26秒选择结构；26–31秒只作F4内部晚段检查。
- F5不参与参数估计或结构选择，固定模型后检查3–31秒激励与31–36秒回零。
- F4/F5 在本分析开始前已经被查看，因此 F5 仍是开发检查，不追溯标记为正式独立验证。
- R1不参与植物模型选择，只保留为线缆和低速工作点诊断。

共检查1620个候选：位置 ARX 的普通最小二乘/工具变量各162个；固定运动学速度状态模型的软件命令
输入和反馈电流输入各含普通最小二乘/工具变量324个。候选只在F4选择，F5结果未用于回头挑选模型。

## 模型结构与结果

### 位置 ARX

位置 ARX 直接用过去关节位置和软件命令预测下一位置。选中的工具变量结构为：

- 8个位置滞后；
- 1个命令滞后；
- 2个20 ms输入延迟；
- 方向摩擦项；
- ridge 0.01。

它在F5激励段的大轴预测比保持退化9.4%，小轴只改善23.4%；回零段RMSE为8.803°/7.046°。
短选择窗口曾显示65.2%/74.9%的改善，但长窗口立即失败，说明近积分位置 ARX 会产生误导性的局部
拟合结果。

### 固定运动学速度状态模型

模型固定 `q[k+1]=q[k]+20 ms·v[k+1]`，只辨识速度动态。F4选择出的工具变量候选为：

- 4个速度滞后；
- 2个软件命令滞后；
- 离散样本延迟0，即实际总延迟小于20 ms、由命令滞后共同描述；
- 加入位置项和速度方向项；
- ridge 0.01；
- 每次只用0–3秒前缀更新常值速度扰动，其他动态系数保持冻结。

| 检查段 | 大关节 RMSE | 小关节 RMSE | 相对保持改善（大/小） |
| --- | ---: | ---: | ---: |
| F4连续3–31秒 | 1.593° | 1.820° | 35.1% / 44.0% |
| F4晚段26–31秒 | 0.601° | 0.969° | 78.3% / 62.3% |
| F5连续3–31秒 | 2.161° | 2.307° | 30.5% / 43.9% |
| F5回零31–36秒 | 4.836° | 2.941° | 明显劣于保持 |

运动段跨幅度复现成立，回零失败说明慢/DC行为没有被同一个固定模型描述。前三秒常值扰动估计在
F4和F5上的归一化小轴值分别为 -0.0803、-0.0410，运行后仍出现大漂移，进一步证明负载状态不是
一个固定偏置。

### 反馈电流作为输入

把每次前三秒中位数从原始电流中扣除，再辨识电流到关节的速度状态模型。选中的工具变量候选在
F5激励段RMSE为2.500°/2.748°，相对保持只改善19.6%/33.1%；回零段为4.990°/2.950°。
大轴没有达到20%诊断线，整体不优于软件命令输入。

这不表示电流没有物理意义。当前反馈电流未经扭矩标定，且闭环电流、软件命令、位置误差和 PID
积分项共同变化；扣除一个运行前中位数不能使其变成外生扭矩输入。

### 航向观测

F4 3–18秒得到的静态局部映射为：

`heading ≈ 0.456·q_big + 0.622·q_small + 0.409°`

在F5激励段RMSE为1.366°，相对保持改善37.3%，最大误差4.919°。它明显不同于简单平面和
`q_big+q_small`，但误差仍过大，不能作为最终倾斜、平行偏置安装的航向几何标定。

## 为什么尚未得到开环植物

1. 软件命令由现有 PID 根据同一批位置误差生成，是闭环内生输入。参考量工具变量在动态频带上足够强，
   但不能恢复缺少独立变化的慢速和稳态模式。
2. 位置、方向摩擦和常值运行前偏置可以改善运动段，无法描述回零后的滞回、PID积分状态和慢负载变化。
3. 原始反馈电流混合传感器零点、保持负载和闭环作用，尚未转换成可归因的关节扭矩。
4. 短时滚动预测每次由真实测量重新初始化，所以不会暴露同等程度的慢漂移；连续自由运行会将该问题
   完整积累出来。

入口：在明确保留的内环边界之外注入已记录、与位置误差独立的双轴命令扰动，同时继续使用现有行程、
反馈、心跳、遥控急停和输出限幅。参考轨迹负责维持工作点，附加命令多正弦负责提供植物输入。

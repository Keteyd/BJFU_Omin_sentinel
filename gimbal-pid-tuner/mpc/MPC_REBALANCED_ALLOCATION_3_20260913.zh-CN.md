# `0x59490907` 第三次大小 Yaw 控制分配调整

现场确认 `0x59490906` 的方向有效：小 Yaw 更稳，整体效果继续改善。当前剩余现象是小 Yaw 急停时，大 Yaw
仍有惯性随动和震荡。`0x59490907` 继续降低小关节回中权重，并提高大 Yaw 速度参考变化代价。

## 权重变化

| 项目 | `0x59490906` | `0x59490907` |
|---|---:|---:|
| 小关节回中权重 | 10 | 5 |
| 大 Yaw 参考变化代价 | 5.0 | 10.0 |
| 航向误差权重 | 300 | 300 |
| 大/小 Yaw 参考代价 | 0.16 / 0.02 | 0.16 / 0.02 |
| 小 Yaw 参考变化代价 | 0.5 | 0.5 |

普通 MPC 速度参考和变化率仍不作限幅。速度 PID 的电机输出限幅、大/小 Yaw 反馈保护、遥控退出以及小 Yaw
机械边界保护继续保留。

## 冻结模型对比

在 10° 航向阶跃中，大 Yaw 参考峰值从约 `36.1°/s` 降至 `20.0°/s`，小关节预测最大偏移从约
`9.47°` 增至 `10.60°`。

在 `30°/s` 航向目标保持 1.2 秒后直接归零的急停场景中：

- 大 Yaw 最大单拍参考变化从约 `4.47°/s` 降至 `1.80°/s`；
- 大 Yaw 参考峰值从约 `73.7°/s` 降至 `58.8°/s`；
- 小关节预测最大偏移从约 `11.3°` 增至 `20.7°`，距正向模型边界 `26.08°` 约余 `5.3°`；
- 进入 ±0.2° 的时间从约 `1.52 s` 变为 `1.78 s`。

在大 Yaw 初始惯性速度为 `30°/s` 的场景中，大 Yaw 反制参考峰值从约 `1.49°/s` 降至 `0.83°/s`。
动态闭环谱半径从 `0.954` 增至 `0.977`，仍在单位圆内，但小关节回中慢模态进一步变慢。

该模型没有复现实际机械系统的反向振荡，因此这些结果用于比较控制分配趋势，不能证明实车振荡已经消除。
回中权重低于 5 的扫描结果会在相同急停场景中把小关节推到或越过正向机械边界，本轮不再继续降低。

烧录 `AGVSentinel_Gimbal_59490907.axf`，重启后保持右拨杆 UP，在目标机执行：

```bash
cd /home/nuc11--02/yaw-mpc-rebalanced-59490907

TRACE_PORT=/dev/serial/by-id/usb-Silicon_Labs_CP2102_USB_to_UART_Bridge_Controller_0001-if00-port0

  --port "$TRACE_PORT" --action probe \
  --output "$TRACE_RUN"
```

第一行必须显示 `Firmware 0x59490907, 460800`，且 JSON 中 `error` 为 `null`。使用与上一版相同的操作比较：

1. 小幅左右输入后松杆，观察大 Yaw 的首次随动、反向次数和停止时间；
2. 逐步增加输入持续时间，观察小关节最大偏角；
3. 小关节接近任一机械边界时拨回 UP，不用边界保护代替正常工作区间。

如果本版仍存在明显的大 Yaw 震荡，下一步应增加大 Yaw 实测速度阻尼或采集急停瞬态；继续单独提高变化代价会
进一步延长响应并消耗更多小关节行程。

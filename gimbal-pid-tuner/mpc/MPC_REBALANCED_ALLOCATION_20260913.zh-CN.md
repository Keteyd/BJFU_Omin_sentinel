# `0x59490905` 大小 yaw 控制分配调整

现场反馈：`0x59490904` 取消普通速度参考限制后响应明显加快，但小 yaw 回中倾向过强，实际控制更倾向
使用大 yaw。本版本只重新设计冻结 MPC 的反馈增益，不修改 S1 ARX 模型、速度 PID、20 ms 周期、
300 ms 预测时域以及 `0x59490904` 的速度限幅策略。

## 权重变化

| 项目 | `0x59490904` | `0x59490905` |
|---|---:|---:|
| 航向误差权重 | 300 | 300 |
| 小关节回中权重 | 100 | 30 |
| 大 yaw 参考代价 | 0.16 | 0.16 |
| 小 yaw 参考代价 | 0.02 | 0.02 |
| 大 yaw 变化率代价 | 0.5 | 2.0 |
| 小 yaw 变化率代价 | 0.5 | 0.5 |

小关节仍会缓慢回中，但允许它承担更多短时航向动作。提高大轴变化率代价后，大轴不再为了快速回中而
频繁改变速度参考。

## 冻结模型离线对比

零历史 1° 航向误差的首拍参考从大/小轴约 `6.90/14.74 °/s` 变为 `2.69/15.33 °/s`。
10° 航向误差模拟中：

- 大轴参考峰值约从 `129` 降至 `75 °/s`；
- 小轴参考峰值约从 `176` 增至 `184 °/s`；
- 小关节最大预测偏移约从 `3.4°` 增至 `6.8°`；
- 航向误差进入并保持 `±0.2°` 的时间约从 `0.34 s` 变为 `0.42 s`。

该结果有意用少量理论响应时间换取更少的大轴抢占。机械边界 `-53.68°..26.08°` 及边界制动仍保留。
普通 MPC 速度参考、变化率和目标速度夹紧仍取消，速度 PID 电机输出保持大/小轴 `±30/±6`。

## 现场步骤

烧录 `AGVSentinel_Gimbal_59490905.axf`，重启后保持 UP。目标机执行：

```bash
cd /home/nuc11--02/yaw-mpc-rebalanced-59490905

TRACE_PORT=/dev/serial/by-id/usb-Silicon_Labs_CP2102_USB_to_UART_Bridge_Controller_0001-if00-port0
TRACE_RUN="probe_$(date +%Y%m%d_%H%M%S)"

python3 -u yaw_mpc_probe_cli.py \
  --port "$TRACE_PORT" --action probe \
  --output "$TRACE_RUN"
```

必须显示 `Firmware 0x59490905, 460800` 且 `error` 为 `null`。试验时先将小关节置于中部，使用同一组
短促 MIDDLE 指令与 `0x59490904` 比较大/小轴参与比例、松杆回正和低频振荡。DOWN 仍为原稳定控制。

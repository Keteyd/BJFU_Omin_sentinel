# `0x59490910` 左拨杆 PID 回退模式

本构建保留 `0x59490909` 的 MPC、权重、无普通速度参考限幅策略，以及 MIDDLE 下以小 Yaw 航向为正前方的
底盘平移控制。新增的左拨杆选择只改变 Yaw 控制后端，不改变 MIDDLE 的底盘坐标系和遥控/上位机仲裁。

## 拨杆矩阵

| 右拨杆 | 左拨杆 | Yaw 控制 | 底盘平移坐标系 |
| --- | --- | --- | --- |
| UP | 任意 | Yaw 输出关闭 | 停止 |
| MIDDLE | UP 或 MIDDLE | 当前已验收 MPC | 小 Yaw 当前航向 |
| MIDDLE | DOWN | 原级联 PID、即时跟随 | 小 Yaw 当前航向 |
| DOWN | 任意 | 原级联 PID、即时跟随 | 原大 Yaw/云台坐标系 |

左拨杆 DOWN 取代此前的“大 Yaw 直接速度”试验入口。它不会再绕过大 Yaw 角度环。

## 恢复的原控制器

小 Yaw 使用原 IMU 角度外环和陀螺仪速度内环。大 Yaw 使用 2026-09-07 现场确认稳定的即时跟随策略：

```text
大Yaw参考角 = wrap(大Yaw编码器角 + 方向符号 × 小Yaw关节角)
```

该参考在每个有效控制周期更新，没有 HOLD/边界触发等待、预测提前量或速度前馈。恢复的大 Yaw 启动参数为：

| 参数 | 数值 |
| --- | ---: |
| 角度 PID | 50 / 0.001 / 4 |
| 速度 PID | 0.6 / 0 / 0 |
| 执行量上限 | 30 |
| 速度反馈滤波时间常数 | 0.030 s |

MPC 与 PID 相互切换时会清空大 Yaw 两级 PID 的历史、重新用当前反馈初始化速度滤波，并清空 MPC 历史，
避免把上一后端的积分、微分或预测历史带入下一后端。小 Yaw 机械边界、反馈有效性、遥控失联、调度异常和
右拨杆 UP 停机仍保留。

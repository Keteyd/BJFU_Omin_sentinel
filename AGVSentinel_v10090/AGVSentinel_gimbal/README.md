# AGVSentinel 云台固件

> 本文件夹只用于云台主控板，请勿烧录到底盘主控板。

当前辨识版 `0x59490201` 已改为 **USART1 460800、8N1**，旧 115200 上位机不能直接使用。
20 秒慢速流式固件已编译，配套主机脚本和真实链路验证尚待完成；
烧录后保持右拨杆上置，见 [交付与协议说明](YAW_SLOW_STREAM.md)。

打开 [MDK-ARM/AGVSentinel_Gimbal.uvprojx](MDK-ARM/AGVSentinel_Gimbal.uvprojx)，工程中只有一个 Target：`AGVSentinel_Gimbal`，编译宏为 `BOARD_GIMBAL`。

云台固件负责：

- 读取遥控器接收机并完成整车模式仲裁。
- 控制大 Yaw、小 Yaw、Pitch 和发射机构电机。
- 通过 USART1 共用链路接收云台 PC 的整车决策命令、视觉结果和调参命令。
- 生成最终底盘运动目标并通过 CAN 下发到底盘板。
- 接收底盘板回传的裁判系统信息和在线状态。

通信协议见 [PC_COMM_README.md](PC_COMM_README.md)，软件分层见 [ARCHITECTURE.md](ARCHITECTURE.md)。

此目录保留了公共源码和被角色宏屏蔽的底盘源码，以保证工程可独立维护；底盘固件位于相邻的 `AGVSentinel_chassis` 文件夹。

## 云台稳定闭环

当前为大 Yaw PC 调参版。因高刚性参数引起高频震荡，默认值回退到角度 Kp `2.6`、速度 Kp `0.6`、独立输出上限 `4.0`、滤波时间常数 `30 ms`，不恢复固定限速。新增 USART1 大 Yaw 独立参数写入与回读，只有遥控器在线且上置、Yaw 输出关闭时才接受写入。小 Yaw、Pitch 参数不变。烧录后保持上置，先验证只读参数查询。详见 [PC 调参与回退记录](YAW_COORDINATION.md#pc-tuning-and-oscillation-rollback-2026-09-06)。

2026-09-06 更新：大小 Yaw 默认不设固定转速上限，小 Yaw 同时取消固定目标步长上限。大 Yaw 按左右各自的行程比例计算跟随需求，修正左侧行程短导致跟随请求偏小的问题。保留机械限位、按剩余距离制动、输出保护和大 Yaw 目标超前保护；PID 增益和 Pitch 不变。具体参数、调参兼容性和编译记录见 [双 Yaw 协调策略](YAW_COORDINATION.md#symmetric-relief-and-optional-rate-caps-2026-09-06)。

- 小 Yaw 使用板载 BMI088 的连续 Yaw 角和 Z 轴角速度闭环，遥控器、视觉和 PC 命令修改世界坐标系角度目标。
- Pitch 使用 BMI088 的 Roll 角和 Y 轴角速度作为外环反馈，外环连续生成 DM4310 的位置目标；DM4310 保留 MIT 位置/速度内环。
- 大 Yaw 使用自身编码器完成位置保持和速度闭环，仅在小 Yaw 行程不足时按需跟随；自身 PID 不使用 IMU 反馈，详见 [双 Yaw 协调策略](YAW_COORDINATION.md)。
- 每次从安全模式进入使能状态时，Yaw 和 Pitch 都捕获当前姿态作为目标，避免追逐上次目标而突然转动。
- IMU 未准备好或数据超过 10 ms 未更新时，小 Yaw 输出归零，Pitch 保持当前电机位置；相关电机反馈离线时对应控制轴停止。
- Pitch 在约 `0.15 deg` 姿态误差且角速度低于 `0.020 rad/s` 时冻结电机位置目标，避免静止噪声被积分成肉眼可见的缓慢漂移。
- Pitch 机械端点标定为 `-0.455 / 0.259 rad`，控制目标两端内收 `0.005 rad`。首次有效反馈和电机离线重连后，根据当前位置对齐整数 `2π` 分支；调参 reset 不改变机械端点。位置不匹配标定范围或超出 MIT 编码范围时，不启用 IMU 外环。电机重新上电的偏移是否确实为整数圈，仍需实车复核。

`GimbalYaw_DiagBigEnable` 现默认为 `1`，上置安全模式仍禁止输出。离开安全模式后大 Yaw 保持当前编码器位置，在小 Yaw 接近限位时自动释放行程。首次测试前将小 Yaw 放在外观正中附近，先验证大 Yaw 保持和低速跟随方向。几何跟随方向用 `GimbalYaw_BigReliefDirection` 调整，不要反转编码器伺服极性。Pitch 补偿方向由 `GimbalPitch_ImuDirection` 调整。

当前固件中 `GimbalPitch_ImuEnable` 默认为 `1`，仍受遥控器安全档、IMU 就绪、电机反馈和限位校验约束。固化参数：IMU `Kp=14 / Kd=0.30`，目标速率上限 `2 rad/s`，MIT `Kp=50 / Kd=3.2`，重力补偿 `0.30`。

静态审核与后续实车复核见 [审核记录](../STATIC_AUDIT_2026-09-05.md)。新版 `pitch_tune_cli.py --monitor-only` 可以记录遥控操作而不锁定 Pitch 输入；需要支持 `0x29` 状态回传的审核版固件。

## 小 Yaw 不对称软限位

GM6020 为直驱。外观正中编码器值 `6816`，左机械端点 `7546`，右机械端点 `5458`，详见 [标定记录](YAW_LIMIT_CALIBRATION_2026-09-05.md)。外观正中不等于行程中点。

软限位暂定为外观正中相对角 `-56.678°～+29.080°`，两端各内收 `3°`，正方向朝左。边界前 `8°` 内限制向外的关节速度，截断超出可达范围的目标并清理受限环节的积分；边界处禁止向外输出，允许向内返回。PID 和 Pitch 参数保持不变。

用户已反馈小 Yaw 软限位正常，但这不代表已验证任意速度下的物理制动距离。双 Yaw 协调版烧录后先保持上置、执行 Reset 再 Run；从外观正中附近开始低速验证大 Yaw 保持和跟随方向，不直接用满摇杆或高速视觉测试。
